# LUC Imóveis

Site de pesquisa e curadoria imobiliária com identidade visual industrial, cor verde e desenvolvimento privado. Este repositório pertence à organização Luc-RP, mas o projeto é independente dos outros projetos da organização.

## Primeira etapa: página inicial

- Interface própria, com o Viva Real apenas como referência de navegação, sem copiar marca ou conteúdo.
- Menu: Alugar, Comprar, Lançamentos, Descobrir e Anúncios.
- Busca em destaque, com finalidade, localização e tipo de imóvel.
- Prioridade inicial para galpões e estúdios em Indaiatuba, SP.
- Layout responsivo para celular e computador.

## Etapas futuras

- Área administrativa com autenticação para cadastrar e editar anúncios manualmente.
- Integração com bot somente por fontes e métodos que permitam o acesso automatizado.
- Cadastro voluntário para notificações por e-mail e WhatsApp, com consentimento e controles de privacidade.

## Desenvolvimento

O repositório permanece privado. A prévia de desenvolvimento poderá ser feita pelo GitHub Codespaces; a Vercel fica reservada para uma etapa posterior. Não armazenar senhas, tokens ou dados pessoais no código.

**Situação:** requisitos documentados; a primeira tela é uma prévia visual estática, e a autenticação, o painel e o bot ainda não foram implementados.
